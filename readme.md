# AppSero Client SDK - Modified Version for Own Server

This repository contains a modified version of the AppSero Client SDK. The primary purpose of this version is to collect plugin/theme usage data on a custom server rather than AppSero's official servers at [appsero.com](https://appsero.com).

## Purpose

The modified SDK enables developers to:

- Gather usage data from WordPress plugins or themes.
- Send the collected data to a custom server for analysis and reporting.

## Current Status

- **Custom Server Integration**: This SDK is currently configured to work with my custom server setup.
- **Future Plans**: I may release the server-side implementation as a plugin in the future, enabling others to set up their own custom data collection servers.

## Usage

To use this modified SDK:

1. Replace the original AppSero Client SDK with this version in your project.
2. Configure the SDK to communicate with your custom server by updating the appropriate settings (Namespace,endpoint & etc)
